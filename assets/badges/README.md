## Color Scheme

Badges use the OWNEX brand palette:
- **Blue (#5E6AD2)** - Primary accent, architecture
- **Green (#00E39A)** - Success, completion, passing
- **Orange (#FFB020)** - Intelligence, events, warnings
- **Red (#EF4444)** - Critical, proprietary, errors
- **Gray (#8B8D98)** - Neutral, information
