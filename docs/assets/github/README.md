# GitHub Presentation Assets (AI-generated)

> **Policy**: No SVG, no real screenshots. Every image in this directory is **AI-generated**
> from the prompt library, dark-first, and faithful to the real product surfaces.

| Subdirectory | Contents |
|---|---|
| `hero/` | README hero banners (2400×900 dark/light) + OG crop (1200×630) |
| `logo/` | O+X mark PNGs (alpha/omega/mono) + horizontal lockup |
| `desktop/` | 17 product surface images (1600×1000, dark) |
| `mobile/` | 9 OMEGA mobile illustrations (1290×2796 iPhone frame) |
| `architecture/` | system / mobile / data-flow diagrams (1600×900) |
| `social/` | Open Graph preview (1200×630) |

## How to generate

1. Read the prompt library: [`docs/design/AI_IMAGE_PROMPTS.md`](../../design/AI_IMAGE_PROMPTS.md)
2. Follow batch order + negative prompt for consistency
3. Drop the results here with the exact filenames listed in the registry
4. Validate: [`docs/design/ASSET_REGISTRY.md`](../../design/ASSET_REGISTRY.md)
