## Reels - Generadores Gratuitos / Open Source

### 1. **CapCut** (Desktop + Mobile) - **MEJOR OPCIÓN GRATIS**
- ✅ Completamente gratis (sin marca de agua en versión gratis)
- ✅ Plantillas de tendencia actualizadas
- ✅ Auto-captions, music library, effects
- ✅ Export 4K sin marca de agua
- ⚠️ Desktop app más completa que móvil

### 2. **DaVinci Resolve** (Desktop) - **PROFESIONAL GRATIS**
- ✅ Completo gratis (versión Studio paga solo para features avanzados)
- ✅ Color grading profesional, Fairlight audio
- ✅ Fusion VFX integrado
- ⚠️ Curva de aprendizaje alta

### 3. **Shotcut** (Desktop - Open Source)
- ✅ 100% Open Source (GPL)
- ✅ Multiplataforma (Linux, Win, Mac)
- ✅ Sin límites, sin marca de agua
- ⚠️ UI menos pulida

### 4. **Kdenlive** (Desktop - Open Source, KDE)
- ✅ Open Source (GPL)
- ✅ Multi-track, effects, transitions
- ✅ Buena para Linux nativo

### 5. **OpenShot** (Desktop - Open Source, Simple)
- ✅ Simple, fácil de aprender
- ✅ Open Source
- ⚠️ Menos features avanzadas

### 6. **LosslessCut** (Desktop - Open Source, Fast)
- ✅ Corte rápido sin re-encoding
- ✅ Perfecto para recortar clips largos
- ⚠️ Solo corte, no edición compleja

### 7. **HandBrake** (Transcoder - Open Source)
- ✅ Compresión/optimización para IG (1080p, <50MB)
- ✅ Batch processing

### Mobile Apps (si editás desde celular)
- **CapCut** (iOS/Android) - Gratis, plantillas, auto-captions
- **VN Video Editor** - Gratis, sin marca de agua, keyframes
- **InShot** - Freemium (marca de agua en gratis)

---

### Flujo de trabajo recomendado (Gratis)
```
1. Grabar clips (celular 1080p/4K) → 
2. LosslessCut: recortes rápidos sin re-encode →
3. CapCut Desktop / DaVinci Resolve: edición, música, captions, efectos →
4. HandBrake: comprimir a <50MB, 1080p, H.264 →
5. Subir a IG (Reels 9:16, <90s ideal)
```

## Herramientas de Imágenes/Diseño Gratis / Open Source

### 1. **Figma** (Web + Desktop) - **MEJOR PARA DISEÑO UI/GRÁFICOS**
- ✅ Plan gratis generoso (archivos ilimitados, editores ilimitados en drafts)
- ✅ Colaboración real-time
- ✅ Componentes, auto-layout, variants, design systems
- ✅ Plugins gratis (iconos, ilustraciones, mockups)
- ✅ Export SVG, PNG, PDF, JPG

### 2. **Figma Community** (Recursos gratis)
- Mockups gratis (camisetas, posters, packaging, devices)
- Icon sets (Phosphor, Heroicons, Lucide, etc.)
- Ilustraciones (Humaaans, Open Doodles, Blush)
- Plantillas IG Stories/Posts/Reels covers

### 3. **Photopea** (Web - Photoshop clone gratis)
- ✅ Abre PSD, XD, Sketch, AI
- ✅ Capas, máscaras, ajustes, filtros
- ✅ Exporta PSD, PSD, PNG, JPG, SVG, WebP

### 3. **Krita** (Desktop - Open Source) - **MEJOR PARA ILUSTRACIÓN/PINTURA**
- ✅ 100% Open Source (GPL)
- ✅ Brush engines profesionales, brush stabilizers
- ✅ Animación frame-by-frame
- ✅ Gestión de color (CMYK, ICC profiles)

### 4. **Krita** - Para diseño de estampados, patrones, texturas

### 5. **Inkscape** (Vector - Open Source)
- ✅ SVG nativo, SVG 2.0
- ✅ Boolean operations, path effects
- ✅ Export PNG, PDF, SVG, EPS

### 5. **GIMP** (Raster - Open Source)
- ✅ Photoshop-like, capas, máscaras, filtros

### 6. **Canva** (Web - Plan Gratis Generoso)
- ✅ Plantillas IG Stories/Posts/Reels covers

### 7. **Remove.bg** (Web - Gratis 1 crédito/día, API gratis 50/mes)
- Quitar fondo automático

### 8. **Upscayl** (Desktop - Open Source AI Upscaler)
- ✅ Escala 4x gratis, modelos reales/art/anime
- ✅ Batch processing

### 9. **SVG Repo / unDraw / Open Doodles** - Ilustraciones SVG gratis

### 10. **Fontshare / Google Fonts / Font Squirrel** - Fuentes gratis comerciales
