# Plan 0-100: Adriel Webs - Web Design Business

## Visión General
**Adriel Webs** = Servicio de creación y mejora de sitios web para negocios locales.

**Modelo**: Vendes **resultado** (web que convierte), no "desarrollo web".
**Canal**: Google Maps → WhatsApp → Portfolio → Propuesta → 50/50 → Entrega → Mantenimiento
**Stack**: HTML/CSS/JS vanilla → Astro + Tailwind + Cloudflare Pages (gratis)
**Sin llamadas obligatorias**: Todo por WhatsApp + Formulario + Portfolio

- 2 rondas de cambios

### 🟣 PLAN PRO+ - $300k-600k+ ARS
