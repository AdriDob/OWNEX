## Reading guide

- **lean** = side with more total importers (ext+int). It is a *signal*, not a
  verdict: ties (59) are mostly `__init__.py` and low-consumer modules that
  need the 12-criteria comparison before any deletion.
- `int` counts importers *inside* `core/`+`cores/` — high `int` on one side
  means that tree is internally wired to its own copy (reinforces the lean).
- `tests` = test files whose name or content references the module — a side
  whose divergent version breaks its tests loses regardless of importer count.
- Stateful/singleton modules (`database.manager`, both `events.event_bus`,
  registries) can NEVER be split — see ADR-0002 hard rules and ADR-0003.
- `events/event_bus.py`: cores version has 18 ext + 71 int importers vs core's
  4+13 — evidence supports cores as canonical bus (ADR-0003), pending facade.

## Recommended adjudication order

1. **core-wins domains** (46 lean-core): adjudicate content, keep `core/`
   canonical, give `cores/` a compat re-export where consumers demand it.
2. **cores-wins** (9): symmetric — migrate stragglers to `cores/`.
3. **ties** (59): mostly `__init__.py` re-export surfaces — resolve AFTER the
   leaf modules are adjudicated, since `__init__` content follows its package.
4. Never delete a divergent file until its domain's canonical side is chosen
   AND all importers (incl. dynamic `importlib` strings) are migrated.
