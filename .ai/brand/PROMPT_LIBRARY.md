## Prompt Engineering Principles

### Core Style Keywords
- Minimalist
- Professional
- Premium
- Autonomous
- Intelligent
- Clean
- Elegant
- Sophisticated
- Modern
- Dark mode
- Near-black backgrounds
- Subtle gradients
- Much negative space
- Typography-driven
- Hierarchical
- Scalable

### Anti-Patterns (NEVER use)
- Cyberpunk
- Hacker
- Gamer
- Neon
- Saturated colors
- Excessive glow
- Busy patterns
- Cluttered
- Retro
- Vintage
- Cartoon
- Playful
- Cheap
- Generic

### Technical Specifications
- **Aspect Ratio:** 16:9 for heroes, 1:1 for logos, 9:16 for mobile
- **Style Reference:** Linear, Arc Browser, Raycast, Vercel, Tesla, Apple
- **Color Palette:** OWNEX Blue (#3B82F6), OWNEX White (#F0F0F0), OWNEX Gold (#F59E0B), Near-black backgrounds
- **Typography:** Space Grotesk, Inter, JetBrains Mono
- **Lighting:** Subtle, diffused, no harsh shadows
- **Detail Level:** Clean, not hyper-realistic, not cartoonish

## Prompt Iteration Protocol

### Iteration 1: Base Prompt
- Use base template
- Generate 3 variations
- Score and select best

### Iteration 2: Style Refinement
- Adjust style intensity (--stylize)
- Modify color emphasis
- Add/remove elements

### Iteration 3: Detail Adjustment
- Increase/decrease detail
- Adjust composition
- Refine typography

### Iteration 4: Final Polish
- Fine-tune colors
- Adjust lighting
- Final composition check
