## Asset Standards

### File Naming Convention
```
[asset-name]-[variant]-[size].[format]
Examples:
- ownex-logo-horizontal-premium.svg
- ownex-isotype-monochrome-256.png
- hero-banner-minimal-1920x1080.svg
- icon-security-cycle-24.svg
```

### Format Standards
- **SVG:** Vector graphics, logos, icons (primary format)
- **PNG:** Raster graphics, screenshots, photographs
- **JPG:** Photographs, complex images (lossy compression acceptable)
- **WebP:** Modern web format, optimized for web

### Size Standards
- **Logo:** 16px, 32px, 64px, 128px, 256px, 512px, 1024px
- **Icon:** 16px, 24px, 32px, 48px, 64px, 128px
- **Banner:** 1920x1080 (desktop), 1080x1920 (mobile)
- **Screenshot:** 1920x1080 (desktop), 1080x1920 (mobile)
- **Wallpaper:** 1920x1080, 2560x1440, 3840x2160

### Color Standards
- **Primary:** OWNEX Blue (#3B82F6)
- **Secondary:** OWNEX White (#F0F0F0)
- **Accent:** OWNEX Gold (#F59E0B)
- **Background:** Near-black (#050505, #080808, #0F1117, #14161E)
- **Status:** Success (#22C55E), Error (#EF4444), Warning (#F59E0B)

### Typography Standards
- **Display:** Space Grotesk, Inter
- **Body:** Inter, system-ui
- **Mono:** JetBrains Mono, Fira Code

## Version Control

### Version Numbering
- **Major:** Redesign, significant visual change
- **Minor:** New variation, refinement
- **Patch:** Bug fix, adjustment

### Version History
```
v1.0 - Initial brand assets (current)
v1.1 - Logo redesign (planned)
v1.2 - Icon system refresh (planned)
v2.0 - Complete brand evolution (future)
```

### Archive Policy
- Keep previous versions for 6 months
- Archive in assets/branding/archive/
- Document rationale for changes
- Maintain backward compatibility where possible

## Quality Control

### Pre-Release Checklist
- [ ] Matches brand guidelines
- [ ] Correct color values
- [ ] Proper typography
- [ ] Scalable (if vector)
- [ ] Correct dimensions
- [ ] Proper file format
- [ ] Optimized file size
- [ ] Consistent with system
- [ ] Professional aesthetic
- [ ] No visual artifacts

### Approval Process
1. Designer creates asset
2. Self-review against checklist
3. Art Director review
4. Visual QA check
5. Brand Designer consistency check
6. Final approval
7. Asset registry update
