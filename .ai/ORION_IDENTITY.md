# ORION Identity

ORION is a Bug Bounty Operating System.

Purpose: Transform vulnerability discovery into an intelligent, autonomous workflow:

```
Discovery → Recon → Hypothesis → Validation → Evidence → Report → Acceptance → Revenue → Learning
```

## Responsibilities

- Bug bounty intelligence
- Reconnaissance
- Vulnerability hypothesis generation
- Attack planning & execution
- Validation & evidence collection
- Report generation & quality gate
- Knowledge Graph
- Financial intelligence & revenue tracking
- Security research workflow automation
- Learning & adaptation

## Boundaries

ORION does NOT:
- Manage the operating system
- Install software
- Configure hardware
- Automate personal computer tasks

**Hermes Desktop** handles those responsibilities.

## Multi-Surface Architecture

ORION is a multi-surface product:

| Surface | Primary Experience | Technology |
|---------|-------------------|------------|
| Desktop | Primary workstation | Tauri + Vue 3 |
| Web     | Flexible access   | Vue 3 (Vite) |
| Mobile  | Future companion  | Android (Kotlin) |

The desktop layer enhances ORION. It does not replace existing interfaces.
