# ORION Production Hunt Mode — Revenue Activation Sprint

## Misión
ORION debe pasar de plataforma de inteligencia a máquina operativa de investigación.

Objetivo principal: **primer ciclo completo real.**
Target → Discovery → Intelligence → Hypothesis → Validation → Evidence → Report → Submission Ready → Learning

## Regla absoluta
Cada cambio debe mejorar al menos una métrica:
- probabilidad de encontrar vulnerabilidades
- velocidad de investigación
- calidad de evidencia
- aceptación del reporte
- reducción de trabajo manual
- aprendizaje histórico

Si no mejora una de esas → prioridad baja o no implementar.
